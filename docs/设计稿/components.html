分辨率与窗口适配

Desktop-first 企业工作台：设计基准 1440×900（本画板即此档），最小可用窗口 1024×680；平板（768–1023）全功能布局重组，手机（<768）只保浏览与轻交互（审批/通知/对话/检索）。玻璃固定层 + 内容滚过 = 液态玻璃的最佳展示位。
