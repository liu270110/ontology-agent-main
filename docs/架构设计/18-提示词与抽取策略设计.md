# 18 - 提示词与抽取策略设计

> 状态：v0.1 草案（模板正文实施期填充，输出契约与结构本篇定稿） | 日期：2026-09-26 | 上游依据：04/06/07 篇、宪法第 2/3 条

本篇**管**：提示词模板的版本化治理、四类抽取模板与六个 LLM 位（记忆沉淀 / L3 冲突判定 / 术语对齐 / 社区摘要 / 推理分支 / 工具投毒检测）的结构骨架与**输出 JSON Schema**、Token 成本预算；**不管**：模型渠道与记账实现（12 篇 §2）、抽取流水线编排与冲突分诊（04 篇 §3~4）、mem TBox 内容（06 篇 §3）。模板正文只定骨架要点、实施期填充；输出契约（schema）本篇定稿、完整可校验。宪法两条贯穿全篇：**第 2 条推理分级**——LLM 只做低频复杂语义判断，输出一律过确定性校验（JSON Schema / SHACL / 规则）才可采纳；**第 3 条候选非成品**——LLM 产出只进候选区，经门禁或人工终审才升级（统一信封见 §3）。

## 1. 提示词治理：提示词是版本化资产

### 1.1 资产模型与变更流程

- `PromptTemplate`：`id / name / kind / version / body / schema_ref / few_shot_refs / model_hint / evalset_ref / status / created_by`；kind 与本文各节一一对应：`extract.text / extract.data / extract.flow / extract.multimodal / memory.settle / memory.conflict / term.align / community.summary / reasoning.branch / tool.poison`。
- **变更走 ChangeRequest 同款流程**（与 07 篇 §2 同构）：`draft → reviewing（审批中心）→ active → deprecated`；active 后不可变，修错发新版本，正文 / schema / few-shot 任一变更即构成变更集，评审材料必附 §1.3 回归报告。**版本钉死（version pin）**：运行期只调 active 版本，任务定义显式记录 `模板 id@version`，同一 job 全程同版本——回归可复现、成本可归因（template_ref 进 llm_calls，12 篇 §2.5）。

### 1.2 模板引擎约定

- 渲染引擎 = **Jinja2 严格子集**：仅 `{{var}}` 插值与槽位，禁循环 / 分支 / 过滤器——模板可静态校验（变量完备性、注入位存在性进 CI）。统一占位：`{{system_role}}`（角色与规则）、`{{output_schema}}`（schema_ref 序列化注入）、`{{few_shot}}`（样例槽位）、`{{input}}`（业务输入区）。
- few-shot 样例是**独立版本化资产**（FewShotSet，更新走同款评审），每集必含正例 + 拒绝例（教模型何时不抽、何时输出 uncertain）；动态取值域（TBox 类 / 属性清单）以注解位 `x-oa-dynamic-enum` 标记，渲染时展开为 enum 下发（合法 JSON Schema 注解关键字，不破坏可校验性）。

### 1.3 评测集与基线

- 每类模板配评测样例集（输入样例 + 期望输出 + 评分口径）：抽取类 = 字段级 F1 + schema 通过率 + 出处 span 命中率；判定类（记忆 / 术语 / 投毒）= verdict 一致率；摘要类 = 忠实率（断言须能在输入事实中定位）+ 覆盖率。
- 任何变更（正文 / schema / few-shot / model_hint）CI 强制跑回归：字段 F1 降 > 2pp 或 verdict 一致率降 > 3pp（初值）即评审打回；基线指标与评测集版本记录在 PromptVersion 上。

## 2. 四类抽取模板（04 篇 §3.2 分类型抽取的落地）

公共硬要求：① 每个候选必带 `source_ref`（§3 `$defs.source_ref`：document_id + doc_version + chunk_id + span 四元组必填，doc_version 参与哈希——04 篇 §3.2）；② 候选之间不得互为证据（佐证计数只认终审事实）；③ 只输出符合 `{{output_schema}}` 的 JSON，依据不足输出空集或 null，禁止先验补全。

公共分片与批处理：结构感知分片优先（标题 / 条款 / 表格 / 图边界），纯文本 ~1200 token/片、重叠 10%~15%；单次调用打包多切片（批内逐切片标 chunk_id），输入 ≤ 8k tokens/次；经 `kb.step.extract` 执行（12 篇 §4.1：online 队列、超时 60min、重试 3 次、幂等键 job_id+batch 序号）。公共失败与重试：JSON / schema 校验失败携错误回注重试 ≤ 2 次（模型侧），仍失败按批次 stage 级重试（队列侧 3 次），耗尽批次标 failed 转人工——**禁止静默丢弃**，已产出候选作废不污染候选区。各类要点与 schema 差异如下（`$ref` 指向 §3 $defs，合并后整体可校验）。

### 2.1 文本知识类（extract.text）

- system：领域知识抽取员，只依据给定切片，产出实体 / 关系 / 属性三类候选，类型限于注入的 TBox 清单，不确定置 null；用户段 = 术语表摘录（term / alias 供预对齐）+ 切片正文（带 chunk_id）+ 文档元数据；few-shot 2~3 例（含 1 个拒绝例）。分片差异：标准条文按条款边界整条不切断。
```json
{ "type": "object", "required": ["entities", "relations"], "additionalProperties": false, "properties": {
  "entities": { "type": "array", "items": { "type": "object", "required": ["name", "type", "source_ref"], "additionalProperties": false, "properties": {
    "name": { "type": "string", "minLength": 1 },
    "type": { "type": "string", "x-oa-dynamic-enum": "tbox_class_iris" }, "definition": { "type": ["string", "null"] },
    "attributes": { "type": "array", "items": { "type": "object", "required": ["predicate", "value", "source_ref"], "additionalProperties": false, "properties": {
      "predicate": { "type": "string", "x-oa-dynamic-enum": "tbox_property_iris" },
      "value": { "type": ["string", "number", "boolean", "null"] },
      "source_ref": { "$ref": "#/$defs/source_ref" } } } },
    "source_ref": { "$ref": "#/$defs/source_ref" } } } },
  "relations": { "type": "array", "items": { "type": "object", "required": ["subject", "predicate", "object", "source_ref"], "additionalProperties": false, "properties": {
    "subject": { "type": "string", "description": "实体 name，入库时经术语对齐换绑 IRI（04 篇 §8.2）" },
    "predicate": { "type": "string", "x-oa-dynamic-enum": "tbox_property_iris" }, "object": { "type": "string" },
    "source_ref": { "$ref": "#/$defs/source_ref" } } } } } }
```

### 2.2 数据/表格类（extract.data）

- system：表头 → 属性候选映射（表头语义对齐）；数值 + 单位成对抽取（qudt:unit，07 篇 §3）；表格结构还原在预处理完成；数值新旧不一致不改判，交冲突分诊（04 篇 §4）。分片差异：按表格边界，大表按行组分批、批间重复表头；重试差异：value 类型 / 单位词典校验失败即回注重试。
```json
{ "type": "object", "required": ["records"], "additionalProperties": false, "properties": {
  "records": { "type": "array", "items": { "type": "object", "required": ["subject", "predicate", "value", "source_ref"], "additionalProperties": false, "properties": {
    "subject": { "type": "string", "minLength": 1 },
    "predicate": { "type": "string", "x-oa-dynamic-enum": "tbox_property_iris" },
    "value": { "type": ["number", "string", "boolean"] },
    "unit": { "type": ["string", "null"], "description": "数值必带单位（qudt:unit，07 篇 §3）" },
    "qualifier": { "type": "object", "description": "限定键值，T3 scope 候选（04 篇 §4.1）", "additionalProperties": { "type": "string" } },
    "source_ref": { "$ref": "#/$defs/source_ref" } } } } } }
```

### 2.3 时序/流程类（extract.flow）

- system：步骤节点 / 顺序边 / 前置条件 / 状态流转；行动类候选挂 oa:Action 锚点（07 篇 §3 行动类）；条件分支写 condition，不补全图中不存在的步骤。分片差异：按流程图 / 章节边界，一图一批，跨页流程预处理先拼页；后检差异：悬空转移 / 环检测（确定性）失败即回注重试。
```json
{ "type": "object", "required": ["steps", "transitions"], "additionalProperties": false, "properties": {
  "steps": { "type": "array", "items": { "type": "object", "required": ["step_id", "name", "source_ref"], "additionalProperties": false, "properties": {
    "step_id": { "type": "string", "pattern": "^s[0-9]+$" },
    "name": { "type": "string", "minLength": 1 }, "description": { "type": ["string", "null"] },
    "precondition": { "type": ["string", "null"], "description": "前置条件原文，终审后结构化为 SHACL / ASK 模板（07 篇 §3）" },
    "action_candidate": { "type": "boolean", "description": "是否行动类候选（oa:Action 锚点）" },
    "source_ref": { "$ref": "#/$defs/source_ref" } } } },
  "transitions": { "type": "array", "items": { "type": "object", "required": ["from", "to", "source_ref"], "additionalProperties": false, "properties": {
    "from": { "type": "string" }, "to": { "type": "string" }, "condition": { "type": ["string", "null"] },
    "source_ref": { "$ref": "#/$defs/source_ref" } } } } } }
```

### 2.4 多模态类（extract.multimodal）

- system：图表 → 结构化描述（图题 / 轴 / 图例 / 数据系列），对预处理 OCR 初值做校正，不臆造图中不存在的数值，span 用 page+bbox。分片差异：一图 / 一页一批，图文交叉引用挂 chunk 链接；重试差异：OCR 低置信区块裁剪重传复核一次。

```json
    "caption": { "type": "string", "minLength": 1 },
    "ocr_text_corrected": { "type": ["string", "null"], "description": "对预处理 OCR 初值的校正结果" },
    "entities": { "type": "array", "items": { "type": "string" } },
    "data_points": { "type": "array", "items": { "type": "object", "required": ["series", "x", "y"], "additionalProperties": false, "properties": {
      "series": { "type": "string" }, "x": { "type": ["number", "string"] }, "y": { "type": ["number", "string"] },
      "unit": { "type": ["string", "null"] } } } },
    "source_ref": { "$ref": "#/$defs/source_ref", "description": "span 取 page+bbox 形态" } } } } } }
```

## 3. 候选非成品输出契约（宪法第 3 条统一信封）

所有 LLM 产出一律封装为统一信封后落库，**只进候选区**（PG candidates / 记忆待复核队列），经 04 篇七步门禁、06 篇 §5.1.1 分级门禁或审批中心终审才升级。candidate_id 与 review.state 由系统回填流转（LLM 只产 payload 与 confidence）；confidence 是门禁与排序参数、非真值；候选不得互为证据。`$defs` 供 §2 / §4~8 的 `$ref` 引用，合并后整体可校验：
```json
{ "$schema": "https://json-schema.org/draft/2020-12/schema", "type": "object",
  "required": ["envelope_version", "candidate_type", "template_ref", "trace_id", "payload", "provenance", "review"], "additionalProperties": false,
  "$defs": {
    "source_ref": { "type": "object", "required": ["document_id", "doc_version", "chunk_id", "span"], "additionalProperties": false, "properties": {
      "document_id": { "type": "string", "minLength": 1 }, "doc_version": { "type": "string", "minLength": 1 }, "chunk_id": { "type": "string", "minLength": 1 },
      "span": { "oneOf": [
        { "type": "object", "required": ["start", "end"], "additionalProperties": false, "properties": { "start": { "type": "integer", "minimum": 0 }, "end": { "type": "integer", "minimum": 0 } } },
        { "type": "object", "required": ["page", "bbox"], "additionalProperties": false, "properties": { "page": { "type": "integer", "minimum": 1 }, "bbox": { "type": "array", "items": { "type": "number" }, "minItems": 4, "maxItems": 4 } } } ] } } },
    "evidence": { "oneOf": [
      { "$ref": "#/$defs/source_ref" },
      { "type": "object", "required": ["kind", "ref"], "additionalProperties": false, "properties": { "kind": { "enum": ["session", "message", "tool_call", "manual"] }, "ref": { "type": "string", "minLength": 1 } } } ] } },
  "properties": {
    "envelope_version": { "const": "1.0" }, "candidate_id": { "type": "string", "description": "系统回填 UUIDv7，LLM 不产出" },
    "candidate_type": { "enum": ["kb.entity", "kb.relation", "kb.record", "kb.flow", "kb.figure", "memory.candidate", "memory.settle_decision", "memory.conflict_review", "term.alignment", "community.summary", "reasoning.assertion", "tool.poison_review"] },
    "template_ref": { "type": "string", "description": "模板 id@version（§1.1 version pin）" }, "trace_id": { "type": "string", "minLength": 1 },
    "payload": { "type": "object", "description": "类特定结构，按 §2 / §4~8 各 schema 校验" },
    "provenance": { "type": "array", "minItems": 1, "items": { "$ref": "#/$defs/evidence" } },
    "review": { "type": "object", "required": ["state"], "additionalProperties": false, "properties": {
      "state": { "enum": ["pending", "conflict_pending", "approved", "rejected"] }, "confidence": { "type": "number", "minimum": 0, "maximum": 1 },
      "reviewer": { "type": ["string", "null"] }, "notes": { "type": "string" } } } } }
```

## 4. 记忆沉淀模板（06 篇 §5.1 沉淀管线）

### 4.1 ADD / UPDATE / SUPERSEDE 决策（memory.settle）

- 确定性捷径先行：同 subject_iri 同属性不同值 → 直接标冲突候选，不进 LLM（06 篇 §5.1）；LLM 只裁断捷径放过的情形。输入 = 候选记忆（抽取 schema 从 mem TBox 生成，06 篇 §7）+ 同 subject 同 record_type 活跃记录集（图 + 向量召回，含 recency / confidence / 出处）。
- 要点：依 recency + confidence 裁断；UPDATE 限"槽位修订"，事实级新旧更替一律 SUPERSEDE（连 mem:supersedes，软删）；**DELETE 不是决策值**——06 篇 §4.2 铁律"任何记忆不物理删除"，失效只有 superseded / invalidated / expired 三态；输出过 mem SHACL shapes 才采纳（ADR-12），rationale 留痕；无增益纯重复不产出决策（抽取侧置信度门禁吸收，显式 NOOP 见 §10）。
```json
{ "type": "object", "required": ["decision", "rationale", "confidence"], "additionalProperties": false,
  "allOf": [ { "if": { "properties": { "decision": { "enum": ["UPDATE", "SUPERSEDE"] } } }, "then": { "required": ["target_record_id"] } } ],
  "properties": {
    "decision": { "enum": ["ADD", "UPDATE", "SUPERSEDE"] },
    "target_record_id": { "type": ["string", "null"], "description": "UPDATE / SUPERSEDE 的目标记忆 id；ADD 时为 null" },
    "patch_fields": { "type": "object", "description": "UPDATE 时 structured 槽位修订子集", "additionalProperties": true },
    "mark_contradicts": { "type": "boolean", "description": "矛盾未消除时同时连 mem:contradicts 边" },
    "rationale": { "type": "string", "minLength": 1 },
    "confidence": { "type": "number", "minimum": 0, "maximum": 1 } } }
```

### 4.2 L3 冲突判定（memory.conflict）

- 时机：L2→L3 升级审批（memory_promotions）前的矛盾对复核；与知识库 T1~T4 分诊互不相通（04 篇 §4.3 边界），判不准输出 needs_human，不许硬判。
- 要点：先比 scope（限定差异 → 双存并各标 scope），再比时间线（版本演进 → SUPERSEDE）；真矛盾给建议胜者但**只建议不终裁**——矛盾记录连 mem:contradicts，进审批中心人工点选（交互对齐 04 篇冲突工单）。
```json
{ "type": "object", "required": ["verdict", "rationale", "confidence"], "additionalProperties": false, "properties": {
  "verdict": { "enum": ["contradiction", "scope_differs", "duplicate", "needs_human"] },
  "suggested_winner_record_id": { "type": ["string", "null"], "description": "仅建议，contradiction 时供工单 UI 参考" },
  "scope_hint": { "type": "object", "description": "scope_differs 时各自限定键值", "additionalProperties": { "type": "string" } },
  "rationale": { "type": "string", "minLength": 1 },
  "confidence": { "type": "number", "minimum": 0, "maximum": 1 } } }
```

## 5. 术语对齐模板（07 篇 §8 / 04 篇 §8.2 第 3 步的 LLM 复核位，term.align）

- 触发位：嵌入相似度 ≥ 0.92 自动绑定、< 0.80 新建候选，均不过 LLM；**仅 0.80~0.92 区间进 LLM 复核**；嵌入 + 编辑距离为确定性双通道（07 篇 §8），LLM 位于双通道之外做语义复核。
- 输入 = 两术语 label + 定义全文 + 各自出处（04 篇 §8.2 原文要求）+ 别名集 + scope。要点：按定义外延 / 内涵逐项对比，同形异义与异形同义都防，字面相似不构成同义证据；不确定必须输出 uncertain → 歧义工单（绑定 / 新建 / 工单三态出口不变）。
```json
{ "type": "object", "required": ["verdict", "rationale", "confidence"], "additionalProperties": false, "properties": {
  "verdict": { "enum": ["same_concept", "different_concept", "uncertain"] },
  "canonical_label_hint": { "type": ["string", "null"], "description": "same_concept 时建议 prefLabel，终审定名参考" },
  "rationale": { "type": "string", "minLength": 1 },
  "confidence": { "type": "number", "minimum": 0, "maximum": 1 } } }
```

## 6. GraphRAG 社区摘要模板（04 篇多粒度，community.summary）

- 层级骨架：L0 叶子社区（实体 + 关系聚类）摘要 → 父层 map-reduce（子摘要归并 + 新增实体）；nightly 只重算标脏社区（kb.community.dirty），产物供 global search（04 篇 §7.1 第 4 路）与实体描述向量。
- 要点：输入只用**已终审事实**与实体（摘要在 Compiled 层、可由 Raw + 事实随时重算，04 篇 §2）；摘要不得引入输入之外的新断言（忠实率口径 §1.3）；findings 必须挂所引事实引用，全程可追溯（宪法第 5 条）。


## 7. 推理分级 LLM 分支模板（07 篇 §5，reasoning.branch）

- 触发：仅路由白名单表中"复杂语义判断"类请求（路由是显式白名单表，非 LLM 判断）；输入 = 待判定问题 + 相关 TBox 片段（类 / 属性 / 公理摘要）+ 事实上下文。提示要点：断言三元组一律用 IRI，rationale 必填，不确定输出空 assertions，输出一律视为候选（宪法第 2 / 3 条双落点）。
- **校验回路**：候选断言 → SHACL / 规则校验（07 篇 §7 LLM 产出门禁）→ 通过：进候选区按 L4 门禁终审；失败：将 violations[]（focusNode / path / message）回注重试 ≤ 2 次；仍失败：**丢弃并记录**（07 篇 §5 原文）+ 事件通知，不阻塞主流程。放弃条件：重试 2 次仍失败 / 上下文超限 / 校验器异常 → 转待办——候选非成品不降质只延迟（12 篇 §2.3 同款原则）。
```json
{ "type": "object", "required": ["assertions", "rationale"], "additionalProperties": false, "properties": {
  "assertions": { "type": "array", "items": { "type": "object", "required": ["subject", "predicate", "object", "basis"], "additionalProperties": false, "properties": {
    "subject": { "type": "string", "description": "实体 IRI" },
    "predicate": { "type": "string", "description": "属性 / 关系 IRI" },
    "object": { "type": ["string", "number", "boolean"] },
```

## 8. 工具投毒检测模板（10 篇 §7 LLM 轨，tool.poison）

- 双轨分工：已知投毒模式**规则库**（确定性）先行，命中即 rejected（10 篇自动门禁）；LLM 轨做语义级一致性审查，输入 = server.json 清单（description / tools schema / network.egress / scopes）+ 静态扫描产物 + 沙箱行为样本。
- 审查要点：宣称能力是否超出 schema 操作面与 scope 声明；description 是否夹带面向 agent 的注入话术（"忽略规则 / 隐藏行为"类）；出网意图与 egress 白名单一致性；pass 也须列出已核查的证据面，不许空泛放行。裁决分流：LLM verdict = fail / suspicious 一律转人工审核（manual_review），**不自动终裁**（宪法第 3 条）；是否允许 fail 直接 rejected 见 §10。
