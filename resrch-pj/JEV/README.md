# JEV 研究归档

> 2026-09-26 调研完成。研究主题：Jev（TypeSafe AI 的"系统一"判定模型）训练原理与开源复现路线，
> 以及由此推导的**本项目本体判定模型设计提案**（见 02）。

## 结论速览

1. **Jev 闭源无论文**。2026-09-15 发布，仅 API（$0.042/M 输入 token，输出免费，70ms/次，
   64k 上下文，单次最多 255 个选项）。技术细节来自官方发布材料与第三方拆解。
2. **核心训练方法 RLCD**（Reinforcement Learning for Calibrated Decisions，面向校准决策的
   强化学习）：与 RLHF 对照——RLHF 优化"人类偏好"，RLCD 优化"输出概率的真实性/校准度"，
   让概率可以直接用作执行阈值。
3. **接口即创新**：输入 = 状态 + 预定义选项（带声明类型）；输出 = 选项 + 校准概率。
   非自回归、单次前向，"不写字"，零幻觉。
4. **开源替代生态**（2 天内出 6 个克隆）：Laya（421M，Convai Innovations，研究轨迹早于 Jev，
   可跑在浏览器里）、Von（395M，ModernBERT 双向）、Kev 等；GLiNER 系（GLiNER/GLiClass/GLiREL）
   被社区认为是"真开源 Jev"。本仓库 tools/jev-local/ 已落地 GLiNER 路线并跑通 GPU。
5. **对本项目的意义**：本体模型的输出接口应当采用 Jev 式"typed value + 校准概率 + 拒答"，
   但骨干与训练走 GLiNER 生态 + 符号内核混合架构（详见 02 提案）。
