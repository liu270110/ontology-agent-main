# 03 · 多专家研讨纪要与技术栈决议

> 2026-09-26。五位专家（知识工程/训练工程/MLOps/行业分析/NLP红队）并行评审 02 提案，
> 本文档是主持人综合：痛点剖析 → 共识 → 争议裁决 → 技术栈决议 → 修订后工程计划。
> 02 提案与本纪要冲突处，**以本纪要为准**。

## 0. 决议速览（十句话）

1. **环境先行**：uv + venv + **Python 3.12**（弃 3.13 全局环境，冻结不再装包），cu128 显式 index。
2. **训练不用 clone 官方仓库**：gliner 0.2.29 pip 包自带 Trainer + 全套 collator（含关系抽取），50 行脚本可训。
3. **精度全线 bf16**（4060 Ada 原生）；首选 **LoRA r=16（冻结嵌入表=省掉 69% 参数）**，全参仅 8bit AdamW 冒烟通过后再议。
4. **标签只用稳定闭集层**（OB2 顶类+国标 15 类+34 属性+行动类属性 ≈60 个，建标签注册表），领域 IRI 永不做训练标签。
5. **头C 收窄**为本体操作五分类（ground/extract/align/validate/reason）+ risk_level，通用意图路由不归它管（那是 Jev 范式/LLM 的事）。
6. **关系抽取改"符号枚举候选 + 头B 打分"**，GLiREL 零样本降为演化备胎（中文无公开证据）。
7. **bge-m3 契约内提召回**：词典精确匹配 + 查询展开 + 混合检索（bge-m3 自带 sparse/ColBERT + BM25），不做投影头、不动主 collection。
8. **校准验收改双集**：冻结 v1 集（覆盖率门禁）+ 模拟演化 v2 集（只报不卡）；abstain ≤20% 写成 SLO。
9. **M1 验收双指标**：域内 F1 ≥ 零样本+10pt **且** 通用零样本 F1 回落 ≤3pt（防灾难性遗忘）。
10. **模型资产 = MinIO + PG 登记（经 MLflow Registry）**，弃 DVC/git-lfs（撞 Gitee 1MB 红线）；Gitee Go 只做 CPU 侧门禁。

## 1. 行业痛点矩阵（行业分析师 + 各专家共认）

| 痛点 | 现有方案缺陷 | 我们的解法 | 量级/证据 |
| --- | --- | --- | --- |
| Agent 幻觉、决策不可审计 | LLM 语义判断概率性，出错不可归因 | 神经感知+符号裁决，结论可归因到具体公理 | AIIA 案例：退单准确率 65%→90%+ |
| LLM 成本与延迟 | 第④类判断全走 LLM，P95≤8s + 上下文注入费 | ~300M 本地模型承接高频判断，LLM 兜底 | P95 8s→约0.2s；成本降 1~2 个数量级 |
| 知识库/标准文档语义漂移 | 纯向量只算相似不算合法，人工建模贵 | 检索前先接地：消歧+术语 lint+公理约束锚定 IRI | GB/T 48000.3 刚发布，附录 D 可反构数据 |
| 信创/数据不出域 | 云 API 出域；8B+ 本地模型吃卡且不可校准 | 8GB 消费级单卡可训可推，输出可验证 | 骨干 fp16≈0.6GB；政企金融硬合规 |

**冷水面**（行业分析师）：①玩具 demo 死法——第一天就建真实验收集，回归每里程碑必跑；②标注成本失控——LLM 造数据+公理负例为主，人工只终审；③被长上下文 LLM 碾压——每里程碑公开跑"vs 长上下文 LLM 零样本"的成本-延迟-F1 三元组，核心卖点从"省成本"转向"可验证+不出域+实时"；④把重本体工程转嫁客户吓跑付费方——坚持三档先轻后重。

**差异化**： Palantir/Fabric IQ 是云端重型平台；国内厂商判定仍靠 LLM 兜底。空位="薄而可校准的判定件"；**公理造负例是独有数据飞轮**（本体公理越全，负例越准——通用 NER 厂商没有这个结构）。

## 2. 共识清单（无争议，直接进计划）

- **jieba 分词一致性写入红线**：数据集存储 tokenized_text、训练端禁止重分词、pin jieba 版本、领域术语 add_word 固化词典、写 char→token 映射器（训练工程+知识工程一致）。
- **审核即标注回灌**：人工终审每次确认/修改自动落为带（本体版本、标签 schema 哈希、审核人）的训练样本（知识工程+MLOps 一致）。
- **公理负例四步管线**：正例 → 按 axioms.kind 扰动算子 → pySHACL/owlrl 验证违规必触发 → bge-m3 相似度 ≥0.9 留"表面困难对"；按扰动模板（非实例）留测试集；混随机负例防捷径学习。
- **通用数据回放 20~30%**（pile-NER/MIT 子集）防遗忘；EWC 性价比低不采用。
- **提名召回率列为一级指标**：神经头提不出的候选符号内核永远看不见，必须度量。
- **禁对判定骨干 int8/ONNX 量化**：改 logits 分布 = conformal 覆盖率/ECE 保证失效；bge-m3 可 ONNX int8 下 CPU（ONNX Runtime，非 OpenVINO——N 卡）。
- **首战钉死标准文档场景**（国标数字化刚需窗口 + 训练数据边际成本最低）。

## 3. 争议与裁决（主持人裁决）

| # | 争议 | 双方 | 裁决 |

| 3 | 关系抽取路线 | 02：GLiREL 零样本 vs 红队：中文无证据、依赖给定实体 | **封闭 34 关系集用 multitask RE 头微调 + 符号按 domain/range 枚举 (s,o) 对只让头B打分**；GLiREL 零样本降为 schema 演化备胎 |

| 数据合成 | LiteLLM JSON mode 模板改写 → char→token 映射 → 严格相等校验+零样本一致性过滤 → MinHash 去重 | 人工 50~200 条只做 dev/test 永不入训练集；双标 10~20% 算 κ≥0.7 |
| 实验管理 | **MLflow 自托管**（backend=PG，artifact=MinIO），Model Registry = 模型资产唯一事实源 | W&B 国内不稳；SwanLab registry 弱 |

## 5. 修订后的训练工程计划（M1 展开）

1. **环境周（先行）**：tools/jev-local 或新训练目录建 pyproject + uv.lock（3.12/cu128/清华）；全局环境冻结。
2. **数据规范周**：标签注册表（≈60 闭集标签 ↔ IRI ↔ 本体版本）；jieba 词典固化 + char→token 映射器；公理负例管线先备好（S1 即用"合成正例+公理负例"，S2 不返工）；LLM 合成管线跑通 200 条。
3. **冒烟**：10-step（pip Trainer + bf16 + batch 2）nvidia-smi 实测峰值 → 定全参/LoRA。
4. **分训→合训**：三头先分训建单任务上界，再合训对比；负迁移 >2pt 回退分头 LoRA。
5. **验收（双指标+新指标）**：域内 F1 +10pt、通用零样本回落 ≤3pt、提名召回率达标、（M2）双集覆盖率。

## 6. 专家原始报告索引

五份报告全文见会话记录；关键增量发现：
- 训练工程：gliner 0.2.29 pip 包已内置 training/trainer.py 与 RelationExtraction collator（本机实测）；transformers 5.x 训练路径需冒烟（DeBERTa 需显式 eager attention；torch.load weights_only 变更）。
- 知识工程：标签集是推理期输入而非权重——schema 增删类只需换标签参数不需重训（GLiNER 关键结构特性）；deprecate-不改名纪律使存量标注可经 changeset diff 确定性迁移。
- MLOps：git-lfs 对象走 HTTPS 上传会撞 Gitee 1MB 红线——DVC/git-lfs 双弃的直接依据。
- 红队：split conformal 覆盖率依赖可交换性，schema 演化下需按 Barber et al. 2023 (arXiv:2202.13415) 界限做双集验收；GLiNER issue #202 证实中文边界弱点；GLiREL (NAACL 2025, arXiv:2501.03172) 训练数据为英文+依赖给定实体。
