## 与其他目录的关系

- [deploy/](../../deploy/README.md)：**脚本资产**（compose、init-*、.env.example）——可执行物；本目录是**手册**——怎么用这些资产、出了事怎么办。冲突时以 deploy/ 实际脚本为准并回填本目录。
- [docs/architecture/](../architecture/README.md)：架构权威。端口、部署分档、降级矩阵、告警分级的唯一事实源分别是 deploy/README 与锚点 §3.2、08 篇 §5/§6，本目录只引用不重定义。
- [docs/user/](../user/README.md)：面向最终用户的操作手册（与本目录读者不同）。

## 维护规则

1. `deploy/` 脚本或存储结构变更时，同步更新部署手册对应章节（顺序纪律见 deploy/README：先改 06 篇数据契约 → 再改脚本/迁移 → 再改手册）；
2. 每次故障处置后，Runbook 有新增案例或修正的，随复盘更新 §6；
3. SLO / 阈值类数字全部标注「草案 / 实测冻结」状态，冻结即回填并更新本 README 状态行；
4. 本文修改须同步状态行；待办完成打勾并注明结论。
