# 2026-09-26 - 前端页面功能缺口补齐（跨模块协调）

> 权威台账：[docs/架构设计/25-前端页面功能缺口对标与任务清单.md](../架构设计/25-前端页面功能缺口对标与任务清单.md)（缺口明细/对标依据/任务 F-01~F-16 均在那边，本文只记**跨模块协调项**，避免两处记账）。

## 背景

对标 ChatGPT/Claude、Open WebUI、LobeChat/Cherry Studio、Dify/RAGFlow 逐页盘点后确认四大缺口带：对话文件能力（附件上传/知识库挂载/@提及）、对话控制（思考档位/消息操作/临时会话）、会话资产（置顶/文件夹/分享/提示词库）、权限纵深（用户组 Groups/资源级 ACL/权限申请审批对象）。
