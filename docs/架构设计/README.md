## 设计宪法（全项目强制）

继承《本地建模》五原则，作为所有模块设计的硬约束：

1. **OB2 建模法**：对象（第一性）— 行为（改变对象状态）— 规则（不变式、独立定义），以事件串联成逆向闭环。
2. **推理分级**：确定性强的高频逻辑走规则引擎与 SHACL（毫秒级、确定性）；低频复杂语义判断才交给大模型，且输出必须过规则校验。
3. **候选非成品**：LLM 产出（候选本体、候选记忆、候选抽取）一律进入审核队列，人工终审后才入库生效。
4. **最小够用、宁简勿繁**：先划边界再定方案；单体优先，服务按模块边界切分、不到性能瓶颈不拆微服务。
5. **全程可追溯**：知识条目带出处指针，动作带审计记录，变更带版本与回滚。
