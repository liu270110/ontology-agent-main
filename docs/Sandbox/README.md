# Sandbox —— 沙箱与执行环境设计文档

> 本目录对应平台核心服务：**统一沙箱运行时**——agent 会话的默认执行底座（S0）、插件隔离（S1）、流水线执行（S2）、插槽宿主（S3）、评测回放（S4）与训练 rollout（S5）共用同一套供给/隔离/出口/快照设施。
