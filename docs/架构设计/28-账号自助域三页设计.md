## 2. 登录页 v2 `/login`

在 16 篇 §5.1 基线上增四块：

1. **2FA 二步验证**（F-13 落地）：设置页开启 TOTP 后，登录流=密码（16 篇基线）→ **二步验证步**：`InputOTP` 六位码（24 篇 §3.7 已有，粘贴自动分发）或备份码切换；错误三次即重锁整个登录（防撞码）；"信任此设备 30 天"勾选（**服务端签发 device token**，联动设置页设备会话列表）；`POST /auth/login` 密码通过后返回 `200 {mfa_required:true, mfa_token}`（**mfa_token 一次性**），二步以 `mfa_token+otp` 重换 access（契约见 api/01 §5.9，X17）；
2. **忘记密码**：链接→邮件重置流（`POST /auth/password/reset` 请求+重置表单两步，挂账 11 篇邮件通道，P1）；
3. **SSO 入口**（enterprise 档）：企业配置 OIDC 后显示"企业账号登录"按钮（配置面在系统管理，25 篇 P2 项；登录页只留按钮位与发现协议，P2）；
4. **注册说明**：邀请制文案（"账号由管理员/邀请链接创建"+联系管理员），不开放自注册（注册开关在系统管理，25 篇 F-10 配套）。

交互红线：全程不暴露"账号不存在 vs 密码错误"差异（统一 1002 文案，防枚举）；限速沿用既有 5 次/10min 且**二步验证失败同池计数**。

## 3. 主页（工作台）v2 `/`

在画框 02 基线（问候/StatCard×4/最近会话/抽取流水线/快捷入口）上增三块：

1. **通知中心收件面**（F-14 前端闭环）：AppHeader 铃铛 → `NotificationDrawer`（复用 NotificationPanel 容器）：四源聚合（待审批/任务完成与失败/@提及/系统公告），未读分组+来源着色+全部已读；偏好开关（画框 27）与产生联动；站内未读数经轮询/SSE（通道裁决挂 X14）；
2. **"待我办"聚合带**：StatCard 之一扩展为可点击——聚合待我审批（审批中心）、待我终审（抽取审核台 @我）、我失败的未重试任务（任务中心），一键跳对应页带过滤；
3. **新手引导 OnboardingChecklist**（P2 项转正为 P1-lite）：首访五步（改密/建知识库/首次对话/跑一次抽取/进本体工作台），完成即隐；进度存 `/me/preferences`。

克制项：不做自定义小部件拖拽（最小够用）、不做多工作区切换。

## 4. 个人设置 v2 `/settings`（02 篇 P13 节同步落位）

在画框 27 基线上新增/修订五个分区（SettingsShell 左导航续接）：

1. **记忆开关区** `MemorySwitchPanel`（F-13）：总开关（关=不再召回+不再沉淀，语义裁决挂 X10）、"清除我的记忆"（危险确认，产生失效边不物理删除，联动记忆管理页）、个性化程度滑杆（P2 预留）；
2. **默认对话参数**：默认模型渠道、思考档位初值（27 篇 ReasoningEffortPicker 的默认值）、默认 routing（仅对新建群聊生效）——写入 `/me/preferences`，对话页读取作初值；
3. **数据导出** `DataExportCard`：我的会话/记忆/API 调用记录 → 异步导出任务（走任务中心，完成通知下载，保留 7 天）；不作同步打包（宪法 5 可追溯+大文件防阻塞）；
4. **账号注销** `DeactivateAccountDialog`：置底 DangerZone 分区（GitHub 式隔离）——二次确认（输入账号名+confirm_token）→ 停用而非物理删除（与 06/04 篇"不物理删除"调和：出处/审计/知识资产保留，匿名化显示"已注销用户"；清退排期与豁免清单**挂账 11 篇合规裁决**，X17）；enterprise 档需管理员审批后生效；
5. **快捷键**（P2 预留命名区）：仅展示现有 ⌘K/J/K/N 速查表，不自定义（最小够用，25 篇待办第 5 条维持）。

## 5. API 预登记（落 api/01）

- **§5.9 auth 扩展**：`POST /auth/login` 增 MFA 两段式（`200 {mfa_required, mfa_token}`，mfa_token 一次性 → 携 `mfa_token+otp` 重登）；TOTP 管理 `setup/enable/disable` 三端点（兑现 26 篇 IX-SET-02 引用）；新增 `POST /auth/password/reset`（忘记密码两步，挂账邮件通道）；
- **§5.13 me（新 router，预登记）**：`GET/PUT /me/preferences`（主页引导/默认对话参数/界面偏好）、`PUT /me/memory-settings`（记忆总开关，联动记忆域）、`POST /me/export`（202→异步导出任务）、`GET /me/sessions`（设备会话列表已有基线则并入）、`POST /me/deactivate`（注销申请，confirm_token；enterprise 档转管理员审批）。scope 复用 `auth:write`/新增 `me:write`（挂账 11 篇 §2/§3）。

## 7. 宪法对齐自检

注销=停用+匿名化+保留出处与审计（宪法 5/不物理删除调和，最终口径挂 11 篇）；导出走异步任务（可追溯、可审计）；通知聚合只读不产生副作用；2FA 失败计数与登录限速同池（安全水位不放宽）；记忆开关"关"只停新增与召回、已沉淀记忆走既有失效边语义（不改记忆系统既有裁决）。
