## 1. 使用说明

- 本集按十个域组织用例，共 **146 条**；每条是"开发的验收合同"（策略篇 §1.1）——对应模块动工前，其域内用例必须先行评审通过；
- 域内排序原则：安全红线与并发类在前、功能与边界在后；同域用例可共享环境加速执行，但**任意用例必须可独立运行**（不依赖表内先后）；
- **追溯列**指向上游文档具体条目，缩写约定：`01/02/03/04/08` = architecture 分篇（如 `04§2` = 04-领域层设计 §2 不变式总表）；`本体` = docs/ontology/本体核心设计.md；`回写` = docs/MCP/业务回写设计.md；`Agent` = docs/Agent/Agent服务设计.md；`11` = docs/architecture/11-链路排查与模块痛点台账.md（后二者为 2026-09-26 痛点优化新增引用）；
- 用例 ID 规范 `TC-{域}-{三位序号}`，**只增不改**：语义变化时废弃旧 ID（标 deprecated）并新增，禁止复用（维护规则见 [README](./README.md)）。

列语义：

| 列 | 含义 |
| ---- | ---- |
| 前置条件 | 用例执行前必须成立的系统/数据状态 |
| 步骤 | 可执行的操 作序列（"；"分隔） |
| 期望结果 | 可判定的断言（含错误码/事件/状态） |
| 优先级 | P0 红线/主链路；P1 关键功能；P2 重要；P3 一般（定义见策略篇 §5） |
| 类型 | 正向 / 反向 / 边界 / 并发 / 故障注入 / 安全 / 审计 / 门禁 / 性能 |
| 自动化层级 | 单测(L4) / 集成(L6) / golden / 契约 / E2E / 性能 / 演练 / 静态（对应策略篇 §2 七层，CI 阶段映射见 README §4） |
