## 3. 记录不修（含理由）

- 登录条款行/时间线次要文字对比度：非关键文本（WCAG incidental），保持 Apple 式低存在感；
- 低密度页下部留白：设计稿为固定 720px 画框，真实页面高度随内容自适应；
- 本体工作台边标签遮挡/图谱节点聚上部：静态稿局限，实现期由 React Flow 布局引擎处理；
- 知识库行尾"…"24px：桌面档可用，触屏档（md/sm）按 03 篇 §2.6 提升至 44px。

## 4. 流程改进（本轮教训，写入 23 篇执行）

1. **代码化修改三步验证**：写 → 重读断言 → 视觉/DOM 硬校验（本轮 3 次 replace 静默失败被此拦截，1 次逃逸由逐页视觉复查兜住）；
2. 截图时序：入场动画会捕到中间帧，验收截图前等动画完成或启用 reduce-motion；
3. **暗色是独立验收面**：亮色修复 ≠ 暗色修复，两主题必须各自截图核验。
