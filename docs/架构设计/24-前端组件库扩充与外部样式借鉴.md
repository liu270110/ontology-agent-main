### 2.3 与我们架构的对齐说明

DSH 的"一切皆插件 + 只追加事件日志"与本平台 05 篇"插件一入口"（ADR-9/10/11）和 08 篇会话事件流高度同构，因此其前端模式**可直接映射**而非类比：Cordis 插件 ≈ 平台插件/MCP 工具；运行模式 preset ≈ AgentSlot；Trajectory ≈ 审计 + 会话回放。差异点：我们是**本体语义基座**，所有插件卡要多一层"本体语义标注"（对应哪个对象/行动类）——这是 DSH 没有的，必须保留为我们卡片的信息优势。

## 4. CSS 样式吸收（可直接落地的模式）

全部经令牌化改造后使用，禁止抄原站色值：

1. **Radix 12 阶色阶**：`--accent-1..12` 亮暗两套（1 页面着色 / 3 边框 / 6 hover / 9 实底 / 10 实底 hover / A 透明阶）——替换现零散 `--accent-soft` 用法（兼容别名保留）；
2. **玻璃 hover 光扫**（Magic UI shimmer 改造）：`.glass::after` 45° 高光细带 `translateX(-100%)→(100%)` 700ms `ease-apple`，仅 hover 触发一次，`prefers-reduced-motion` 关闭；
3. **accent 光晕**（glow）：主 CTA `box-shadow: 0 0 0 1px var(--glass-border), 0 8px 32px var(--accent-soft)`；选中图谱节点光晕已有同款，统一为 `--glow-accent` 令牌；
4. **终端卡**（DSH）：`--surface-2` 底 + 发丝线圆角 12 + mono 13px + `$` 提示符 label-3 色 + 右上复制按钮（hover 显现）；
5. **来源着色体系**（DSH Trajectory）：系统提示词=indigo / 工具调用=teal / 子 Agent=purple / 上下文注入=orange / 用户=accent——固定映射写入 tokens（`--src-*`）与 theme.ts，轨迹、审计、通知三处共用；
9. **动效体系**（motion.css，2026 微交互趋势：克制、传递状态）：入场 `anim-fade-up/scale-in/slide-in-*` + 列表 `stagger`；运行态 `pulse-ring`（呼吸点）/`stream-caret`（流式光标）/`spin`；加载 `skel-animated`（shimmer 骨架）/`indeterminate`（不确定进度）；玻璃氛围 `glass-sheen-loop`（光扫循环）/`blob-drift`（登录光斑漂移）；反馈 `hover-lift`/`pressable`/`tick`（数字变化）；主题切换交叉淡化 `.theme-fading`。全部走 `--dur-1..4` 时长令牌，无限循环仅限运行态与氛围层，`prefers-reduced-motion` 全量降级。设计画板已实装（滚动入场 IntersectionObserver + 循环动效实演 + 重播按钮），动效验收 = 打开画板直接看，不看静态截图。
6. **批量操作浮条**：底部居中玻璃 Regular 胶囊（`inset 高光 + sh-float`），出现弹簧 morphing；
7. **时间线左轨**（Geist）：2px 轨道 label-3 色 + 12px 状态点（语义色）+ 相对时间 caption；
8. **表格式密度**（Linear）：行高 36px、hover 行底 `--surface-2`、选中行左缘 2px accent——DataTable 与审核队列共用。

## 4.10 液态玻璃效果库（开源社区配方，v1.5 已实装）

用户指令"去开源社区找 CSS 效果"后收录的八大配方，全部令牌化进 `styles/glass.css`，实演在组件库页：

| 效果类 | 来源 | 技法 | 用途 |
| ---- | ---- | ---- | ---- |
| `.glass-aurora` | Magic UI Aurora | 多色 radial + blur(28px) 交替漂移（`--aurora-1..3`） | 主卡/登录/空态氛围 |
| `.border-flow` | Aceternity BorderBeam | `@property` 角度动画 + conic 渐变 + mask 描边 | 选中/重点卡片流光边 |
| `.glass-noise` | shuding/liquid-glass | SVG feTurbulence 噪点 overlay | 消除磨砂 banding |
| `.glass-spotlight` | Aceternity Spotlight | 指针跟随 radial 高光（JS 三行写 `--mx/--my`） | 可交互卡 hover |
| `.iridescent` | 社区全息配方 | 五色 linear 流动 + screen 混合 14% | 品牌区/徽章 |
| `.glass-lens` | Hyalite 透镜思路 | 四向镜面内阴影 bevel | 与任意玻璃叠加 |
| `.glass-deep` | huozhi/vaso 思路 | 深色媒体玻璃档 | 媒体/插画之上 |
| `.blob-morph` / `.float-y` | 氛围层 | border-radius 形变 / 轻浮动 | 登录页/空态背景 |

组合推荐：**主卡形态 = `.glass.glass-aurora.glass-lens`**；全站 `.card` 已升级为玻璃材质（配彩色氛围底，玻璃才有内容可折射）；基础玻璃 Regular 透明度 .52、描边 .7、saturate 220%（更透更液）。诚实声明：Apple 官方仅 Apple 平台有 Liquid Glass，Web 全部为社区再创作（SVG 滤镜/WebGL/backdrop 近似），v1 采用 backdrop 近似保证全浏览器一致，SVG 位移折射留 Chromium 增强位。
