# Agent 工作区与文件管理（workspace & files）

> 状态：v0.1 | 2026-09-26 | 参照：Claude Code 文件工具 ACI（错误为模型设计）、[DSec](../Dsec/DSec-技术报告.md)（workspace 版本化层+pack_diff 快照）、[Hermes](../研究整理/01-Agent工具调研.md)（文件操作经 RPC、随 7 种后端挂载）；承接：[内核/能力层](./02-Agent内核与能力层划分设计.md)（沙箱代码行动类）、任务本体 Artifact 类、[资源调度](./03-多Agent资源与调度设计.md)

## 1. 定位与布局

每个 Task 一个**临时工作区**（生命周期=任务；随 execution.backends 挂载，Docker 卷起步）：

```
/workspace        # cwd，可写；任务私有（资源语义=exclusive per task）
  /workspace/in   # 只读挂载：输入 Artifact、检索证据导出、技能资产
  /workspace/out  # 产物收集区：Step 完成时打包为 Artifact（走任务本体 Artifact 类登记）
  /tmp            # 草稿，不归档
```

## 2. 文件工具（ACI 纪律，进 tools.bindings）

`file.read / file.write / file.edit / file.list / file.glob / file.grep / file.stat`——七件套统一约束：**路径监狱**（解析后必须落在 /workspace 内，symlink 逃逸检查，违者结构化报错）；原子写（临时文件+rename）；单文件大小上限（默认 10MB）与工作区磁盘配额；**错误为模型设计**（"文件已被外部修改，请重读"而非裸异常——研究整理 07 §3 规律 3）；file.edit 强制 read-before-write（防盲改）。

## 3. 持久化与复用（DSec 精神）

- **产物即 Artifact**：/workspace/out 打包 → MinIO 版本化工件 → 任务本体 Artifact 实例（可过 SHACL、可评审、可被后续任务只读引用）——文件进入本体语义世界；
- **快照=检查点**：工作区 diff 快照（pack_diff 精神）在关键步后固化，崩溃恢复=快照+账本重放（v2 位已登记 arch07 §4.1，本文为其任务侧语义）；
- 跨任务复用：只引用 Artifact（只读挂载），禁止跨任务直写共享目录（污染面）；
- GC：任务终态后工作区保留 N 天（默认 7）转归档，超期清理。

## 4. 安全与治理

密钥永不入工作区（凭据经 ToolPort 注入调用时使用）；文件内容出工作区（作为 Artifact）时过敏感扫描；上传/生成文件类型白名单；全部文件操作带审计与 trace。solo/team/enterprise 三档不改变文件机制（无审批语义），仅 Artifact 发布走各自档位。
