# pdf-carrier-probe:PDF 载体诊断

摄取 PDF 前先回答一个问题:**它是「矢量 CAD 导出」还是「扫描图像」,文本层能不能直接抽?**这决定后续走文本层解析、OCR 还是视觉通道。本技能用零依赖方式给出客观证据。

## 诊断步骤

1. **跑探针**(纯标准库,无需安装解析库):

   ```
   .venv/Scripts/python.exe tools/drawing-probe/probe_pdf.py "<文件1.pdf>" "<文件2.pdf>"
   ```

2. **按指标判读**(探针输出):

   | 指标 | 含义 |
   | --- | --- |
   | `path_ops_in_streams` 数万级 | 矢量 CAD 导出图(线画密集),必有图形语义层 |
   | `image_xobjects` 多且 DCT/CCITT/JBIG2 编码 | 含光栅对象(扫描件或章戳/签名贴图) |
   | `font_objects` > 0 且 `text_ops_in_streams` > 0 | 有文本层;但 `readable_text_sample` 为 0 段 = 文本走 CID/十六进制编码,普通字面量抽不出,需专业解析库 |
   | `page_objects` | 页数;**多页图纸要考虑套图/跨页关联,不是单文件单图** |
   | `mediabox_mm` | 图幅规格(A3=420×297、A2=594×420 等),工程意义校验用 |

3. **结论三分法**:
   - 矢量导出 + CID 文本层 → 走 PDF 解析库通道(文本层抽取 + 矢量图元),OCR 只补光栅章戳;
   - 纯扫描(路径操作≈0、整页大图)→ OCR/VLM 通道为主;
   - 混合 → 双通道,光栅对象单独导出处理。

## 边界与纪律

- 本诊断只刻画**载体形态**,不解读图纸内容(标题栏/语义判读属摄取链职责);
- 样图文件属客户资产:路径经参数传入,**不硬编码文件名、不入库、不外发**(推送脱敏规范 docs/standards/02 §11);
- 判读结论落到方案文档时,附探针原始数值作为证据。
