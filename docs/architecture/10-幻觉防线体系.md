# 幻觉防线体系（anti-hallucination）

> 状态：v0.1 | 日期：2026-09-26 | 定位：**全平台幻觉治理的总地图**——汇总分散在各篇的既有防线为五层体系，并补四个缺口。本文是汇编与补缺，不重复各层细节（逐层给权威出处）。

## 0. 总原则

幻觉不可根除，只能**分层设防、逐层收窄、全程留痕**：输入侧保证"喂得对"，生成侧约束"答得守法"，输出侧强制"过裁判"，运行侧持续"量得着"，治理侧保证"错了能追、能改"。平台宪法三件（候选非成品/推理分级/全程可追溯）本身就是幻觉治理的骨架——本体是幻觉的**结构化对手**。

## 1. 五层防线地图（既有机制汇总）

| 层 | 防什么 | 机制 | 权威出处 |
| ---- | ---- | ---- | ---- |
| **L-in 输入侧（接地）** | 无据生成 | 检索证据先行（RETRIEVAL_EVIDENCE/citations 只返回 authoritative 数据）；TBox 摘要压缩领域知识；装载确认+re-ground（错误目标不进循环）；记忆读取注入标界+降权 | OntRAG §5、Agent §4.1、memory §9.2 |
| **L-gen 生成侧（守法）** | 越界编造 | 受约束生成（JSON Schema/structured-output，PoC⑤ 兼容矩阵）；工具按行动类裁剪（遮蔽式 schema）；提示词版本化+few-shot 典型样本；规划三档（模板优先少自由生成） | standards §5、Agent §4.1 |
| **L-out 输出侧（裁判）** | 事实错误 | **LLM 输出 100% 回灌确定性校验**（SHACL/规则/一致性，不过则重试≤2→降级安全回答→候选进审核）；判据只认外部回执（信任级防自证）；错误即反馈回流 | 05 §3、ontology §5.4、Agent/02 B2 |
| **L-run 运行侧（量化）** | 静默劣化 | 在线四率（无引用/空检索/degraded/负反馈）；rag_feedback 回流复核；闭包/门禁延迟等指标 | 08 §7.4 |
| **L-gov 治理侧（追改）** | 不可追溯 | 候选非成品（LLM 产物永不为权威）；全程 trace+审计；负反馈→候选复核工单→反哺 | 锚点 §6、08 §4 |

## 2. 四个缺口（本轮补齐）

1. **知识边界声明（unknown 通道）**：Agent 必须能说"我不知道"——检索置信低于阈值/证据冲突未裁决时，编排器强制走**拒答模板**（说明缺什么证据、建议动作），禁止模型在无接地时自由作答。落点：03 篇 chat_orchestrator 步骤 4 增分支（无证据→拒答，SSE RUN 正常结束带 `grounded=false` 标记）。
2. **在线忠实度抽检**：离线 RAGAS 忠实度已有，生产按 1% 抽样异步跑 LLM-as-judge（答案 vs citations 支撑度），`rag_faithfulness_sample` 指标——离线/在线两路闭环。落点：08 §7.4 补一条。
3. **关键事实双采样一致性**：高风险结论（回写决策依据、终审建议）双温度采样对比，不一致即降级为候选+人工——概率输出自检，零新增基建。落点：03 篇 §3 步骤 7 附注。
4. **幻觉事件登记**：`hallucination_confirmed` 事件（复核工单判定为幻觉时发）→ RSI 经验轨输入（同一类幻觉→提示词/检索改进提案）。落点：04 §6.1 事件表 + 09 §2。

## 3. 度量（北极星之外的幻觉指标）

`rag_faithfulness_sample`（目标 ≥0.9）、`rag_no_evidence_answer_rate`（≤10%）、`gate_rejected_total{gate}`（回灌拦截数=被防住的幻觉）、`hallucination_confirmed_total`（漏网确认数）。**防线效果 = 拦截数上升 + 确认数下降**。



## 6. 本体作为幻觉的结构化对手（2026-09-26 增补）

五层防线是通用工程；本体提供的是**只有本平台有的**四件反幻觉武器（机理详见研究整理 07 §4 痛点对照表）：

1. **受控词表生成**：受约束生成的 schema 直接由 TBox 派生——类/属性/枚举值是闭集，模型只能在已知概念空间内选择，**概念混淆型幻觉在词表层灭绝**（配合 §5"值不经采样"）；
2. **术语唯一性消歧**："已完成订单 vs 已结算订单"这类语义鸿沟（AI 落地核心瓶颈）由术语唯一+别名登记消解——同名异义/异名同义在进入模型上下文前已被本体归一；
3. **闭包 = 完备知识边界，unknown 变可判定**：推理闭包给出"平台已知全部"的完备视图，使 §2 缺口① 的拒答从启发式（检索分数低）升级为**可判定**（闭包+检索双查无 = 系统级"不知道"）——这是本体路线独有的能力，纯 RAG 做不到；
4. **证据链路径可验证**：每个结论附图谱路径（实体→关系→出处），忠实度校验有结构化对象可比对，而非自由文本相似度。


## 5. 从大模型内在特性反推的防线（2026-09-26 三角色增补：LLM 专家×Agent 专家×架构师）

| 模型特性 | 幻觉机理 | 工程对策（本平台落点） |
| ---- | ---- | ---- |
| 概率解码，无真值寄存器 | 高置信≠真 | 不信自报置信（PoC② 校准）；裁判确定性化（L-out） |
| **讨好性（sycophancy）：指令微调使模型倾向"总要给答案"** | 被逼着编 | unknown 通道 + 提示词范式明确允许"证据不足即拒答"（提示词模板纳入此措辞规范） |
| **采样随机性** | 同问不同答 | **温度分级策略：事实型任务（抽取/校验建议/回写依据）temp 0~0.2，创作型放宽**——入 ModelPort 请求参数规范；关键事实双采样（已补） |
| **分词器对数字/ID 的碎片化** | 编造订单号/金额 | **值不经采样原则：数字、ID、枚举值一律槽位填充自工具结果/检索命中，模型只选动作与槽位、不造值**——受约束生成的 schema 把这类字段标记为 enum/引用，禁止自由文本 |
| 注意力位置偏置（lost-in-middle） | 中段证据被忽略 | 组装器三断点已定；**证据块置于首尾（primacy+recency）**，关键规则靠前 |
| 权重冻结 vs 事实易变 | 过期知识 | 动态事实全部走本体/ABox 注入（已有）；模型参数知识只用于推理风格不用于事实断言 |
| 长生成误差累积（exposure bias） | 越写越偏 | 分步生成+步级校验（StepState 已有）；长答案分段，每段独立过裁判 |
| 上下文干扰 | 无关上下文拉偏 | 投影裁剪+行动类工具遮蔽（已有） |
