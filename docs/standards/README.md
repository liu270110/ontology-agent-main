## 与 08 篇 §8 的关系

[08-横切关注点与工程规范 §8](../architecture/08-横切关注点与工程规范.md) 是**战略层**（为什么管：质量门禁顺序、测试金字塔、分支模型的原则定义）；本目录是**操作层**（怎么管：具体命令、配置示例、检查清单）。二者冲突时以 08 篇原则为准、回改本目录细则。

## 执行机制

1. **CI 门禁**（硬约束）：lint → typecheck → 单测 → 集成 → 契约 → 前端 build，任一失败阻断合并；import-linter 分层契约违规即构建失败；
2. **评审清单**（软约束）：[01-编码规范 §6](./01-编码规范.md) 后端 10 条 + 前端 8 条逐项过，评审人签字即背书；
3. **文档同步义务**（流程约束）：改接口/表/事件必须在同一 PR 同步对应设计篇（01 篇 §7），缺失即打回。
