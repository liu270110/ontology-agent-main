# 液态玻璃背景图素材（9 张）

> 来源：营销海报拆分（2026-09-26，三轮裁切去遮挡）｜总览图：[textures-overview.png](./textures-overview.png)
> 规格说明：均从海报卡内无遮挡区裁出，尺寸即原始可用尺寸；用作背景时以 `background-size: cover` + 玻璃层叠加使用（浅色素材叠 `.glass-regular`，深色素材叠 `.glass-deep`）。

## 素材清单与建议用途

| 素材 | 尺寸 | 色系 | 建议用途 |
| ---- | ---- | ---- | ---- |
| chrome-blue | 300×600 | 蓝铬 | **主打**：登录页/空态主视觉、报告封面 |
| navy-dark | 205×320 | 深蓝渐变 | 深色卡背景、`.glass-deep` 演示底 |
| pearl-white | 183×180 | 珍珠白 | 浅色面板点缀、卡片局部 |
| smoke-backdrop | 520×47 | 烟雾横条 | 页头横幅/分隔带（宽条，可横向平铺） |
| ice-blue | 137×123 | 冰晶浅蓝 | 小卡/图标底 |
| chrome-silver | 190×163 | 银蓝铬 | 次级卡/侧栏点缀 |
| spiral-deep-blue | 151×267 | 深蓝螺旋 | 竖幅卡/移动端空态 |
| oil-pink | 175×410 | 粉青油彩 | **点缀/特殊场景**（营销横幅、插画区），禁大面积铺底 |
| iridescent-purple | 172×122 | 紫粉幻彩 | 同上，点缀用 |

## 色系纪律（03 篇 §2 颜色规则约束）

蓝族 6 张可常规使用；**粉/紫 2 张仅作点缀或营销场景**，不得进入常规页面大面积背景——中性主导 ≥90% 的纪律优先于素材好看。
