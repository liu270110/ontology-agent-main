## 定位

本目录是平台**数据库 DDL 级设计与初始化**的唯一权威落点：字段类型、约束、索引、分区、非 PG 存储的 DDL 等价物，以及按里程碑的分期建表计划。ORM 模型（`services/data/orm/`）与 Alembic 迁移以本目录为准实现。

## 维护规则（改表流程，顺序不可反）

1. **改 06 篇契约**：新增/修改表、字段、索引要点，先在 [06-数据层设计 §2](../architecture/06-数据层设计.md) 评审定稿；
2. **改本目录 DDL**：按定稿契约更新 01 篇对应域的 CREATE TABLE（领域字段补充标「本篇补充」）；
3. **写 Alembic 迁移**：按 [01 篇 §8](./01-数据库详细设计.md) 命名与四条纪律新增迁移文件（只增不改、结构/数据分离、人工评审、单头收敛）。

任何跳步（直写迁移、只改本篇不改 06 篇）都会造成双源漂移，评审一律打回。
