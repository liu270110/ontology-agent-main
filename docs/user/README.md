## 与 frontend 设计稿的关系

- 本目录操作路径以 [frontend/02-信息架构与页面设计](../frontend/02-信息架构与页面设计.md)（P1~P12、路由、角色）为蓝本编写；
- **实际交互以线上实现为准**：前端实现与手册描述不一致时，以实现为事实回填手册（先改手册再关单），不得反向迁就过期描述；
- 页面结构、快捷键、入口路径的权威变更流程：frontend/02 设计稿评审通过 → 实现落地 → 本手册同步。

## 版本联动规则

1. 前端里程碑（锚点 §7：M3 对话主干 → M5 前端全量）每交付一批页面，同步更新操作手册对应章节并修订状态行；
2. 面向用户的错误码、降级提示文案变更（08 篇 §5 降级矩阵）时更新故障自助章节；
3. 治理档位（08 篇 §2.4）或角色矩阵（08 篇 §2.2）变更时更新第 2 章——本目录只引用权威定义，不重复维护；
4. 本文修改须同步状态行；待办完成打勾并注明结论。
