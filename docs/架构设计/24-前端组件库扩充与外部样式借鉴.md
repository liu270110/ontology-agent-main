## 1. 借鉴官网研究结论

**选择标准**：① 与本项目形态相近（AI 平台 / 开发者工具 / 中后台）；② 视觉或交互模式可被我们的令牌体系（Apple 液态玻璃）吸收而非照搬皮肤；③ 官网/官方文档公开可考。

| # | 来源 | 定位 | 借鉴什么 | 落到哪 |
| ---- | ---- | ---- | ---- | ---- |
| 1 | **DeepSeek Harness**（官网 + 插件中心，用户点名） | 开源 agent harness，"一切皆插件" | 见 §2 深度分析 | 市场卡 / 轨迹回放 / Agent 插槽 / 设置页 |

### 2.3 与我们架构的对齐说明

DSH 的"一切皆插件 + 只追加事件日志"与本平台 05 篇"插件一入口"（ADR-9/10/11）和 08 篇会话事件流高度同构，因此其前端模式**可直接映射**而非类比：Cordis 插件 ≈ 平台插件/MCP 工具；运行模式 preset ≈ AgentSlot；Trajectory ≈ 审计 + 会话回放。差异点：我们是**本体语义基座**，所有插件卡要多一层"本体语义标注"（对应哪个对象/行动类）——这是 DSH 没有的，必须保留为我们卡片的信息优势。

## 4. CSS 样式吸收（可直接落地的模式）

全部经令牌化改造后使用，禁止抄原站色值：

1. **Radix 12 阶色阶**：`--accent-1..12` 亮暗两套（1 页面着色 / 3 边框 / 6 hover / 9 实底 / 10 实底 hover / A 透明阶）——替换现零散 `--accent-soft` 用法（兼容别名保留）；
2. **玻璃 hover 光扫**（Magic UI shimmer 改造）：`.glass::after` 45° 高光细带 `translateX(-100%)→(100%)` 700ms `ease-apple`，仅 hover 触发一次，`prefers-reduced-motion` 关闭；
3. **accent 光晕**（glow）：主 CTA `box-shadow: 0 0 0 1px var(--glass-border), 0 8px 32px var(--accent-soft)`；选中图谱节点光晕已有同款，统一为 `--glow-accent` 令牌；
4. **终端卡**（DSH）：`--surface-2` 底 + 发丝线圆角 12 + mono 13px + `$` 提示符 label-3 色 + 右上复制按钮（hover 显现）；
5. **来源着色体系**（DSH Trajectory）：系统提示词=indigo / 工具调用=teal / 子 Agent=purple / 上下文注入=orange / 用户=accent——固定映射写入 tokens（`--src-*`）与 theme.ts，轨迹、审计、通知三处共用；
9. **动效体系**（motion.css，2026 微交互趋势：克制、传递状态）：入场 `anim-fade-up/scale-in/slide-in-*` + 列表 `stagger`；运行态 `pulse-ring`（呼吸点）/`stream-caret`（流式光标）/`spin`；加载 `skel-animated`（shimmer 骨架）/`indeterminate`（不确定进度）；玻璃氛围 `glass-sheen-loop`（光扫循环）/`blob-drift`（登录光斑漂移）；反馈 `hover-lift`/`pressable`/`tick`（数字变化）；主题切换交叉淡化 `.theme-fading`。全部走 `--dur-1..4` 时长令牌，无限循环仅限运行态与氛围层，`prefers-reduced-motion` 全量降级。
6. **批量操作浮条**：底部居中玻璃 Regular 胶囊（`inset 高光 + sh-float`），出现弹簧 morphing；
7. **时间线左轨**（Geist）：2px 轨道 label-3 色 + 12px 状态点（语义色）+ 相对时间 caption；
8. **表格式密度**（Linear）：行高 36px、hover 行底 `--surface-2`、选中行左缘 2px accent——DataTable 与审核队列共用。

## 6. 样式库落地（已构建）

§4 的 CSS 吸收模式已构建为真实代码，位于 **`frontend/src/design-system/`**（03 篇 §2.5 / 16 篇 L0 规划位置）：

```
design-system/
├── tokens/tokens.css        # 全部令牌（亮暗成对，含 --glass-* 六枚、--edge、--sb-w、
│                            #   --glow-accent、--on-accent、来源着色 --src-*、
│                            #   时长 --dur-1..4、布局令牌）——唯一事实源
└── styles/
    ├── index.css            # 入口：@import 顺序 = 令牌 → 玻璃 → 基元 → 模式 → 动效 → 工具类
    ├── glass.css            # 液态玻璃材质：.glass/.glass-clear/.btn-gl(-p)/hover 光扫/
    │                        #   prefers-reduced-transparency 与 @supports 降级
    ├── elements.css         # 基元：btn 系/input/badge/seg/card/tbl(Linear 密度)/steps/toast
    ├── patterns.css         # 模式：cmdk/tl 时间线/traj 来源着色/term 终端卡/upzone/
    │                        #   batchbar 弹簧浮条/ev-chip/diffline/empty/meter/kbd
    ├── motion.css           # 动效层（§4.9）：入场/stagger/运行态/shimmer/玻璃氛围/主题淡化
    ├── utilities.css        # mono/hairline/scroll-thin/skel/visually-hidden/全局降动效
    └── preview.html         # 冒烟验收页：直接加载真实库文件，亮暗切换核对（改动 CSS 后必看）
```

约定：类名与设计稿画板同名同源（`.glass`/`.btn-*`/`.badge`…），与 Tailwind 共存；组件值只允许引用 `tokens.css` 变量；shadcn 变量映射（`shadcn-mapping.css`）与 `theme.ts` 由 M1 实现时按 16 篇补齐。
