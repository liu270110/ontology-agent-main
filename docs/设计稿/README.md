## 设计约定（评审时请对照检查）

1. **材质 = 液态玻璃（Liquid Glass，v1.1 升级）**：玻璃只给控制/导航层（侧边栏、顶栏、输入栏、悬浮工具条、Toast、登录卡、玻璃按钮），内容层一律实底；玻璃不叠玻璃；分 **Regular**（承载文字，着色 60–72%）与 **Clear**（悬浮控件，着色 30–40%）两档；CSS 分层 = 折射渐变着色 + `blur(24px) saturate(200%)` + 顶部镜面高光 + 底部内阴影 + 半透明描边（画板 00 画框有专属展示块，彩色衬底上可看折射效果）；`prefers-reduced-transparency` 时退化实底；
2. 全部颜色/字号/圆角/阴影只来自 03 篇 §2 令牌（画板 `:root` 与 `.dark` 变量即 tokens.css 的原型，v1.1 新增 `--glass-*` 六枚）；
3. 图标为内联 SVG 线性风格（1.5px 描边，SF Symbols 观感），无 emoji；
4. 图谱画布节点分类色板：purple/teal/indigo/ green/orange（约束）/accent（选中）——节点保持实底（内容层）；
5. 未覆盖页面（知识库列表、Agent 管理、工具与技能、MCP 管理、系统管理）复用本稿骨架，实现前按 16 篇规格补充。

## 动效怎么看（v1.4）

动效是**活的**，静态截图看不到：打开画板后①滚动页面——各画框标题与卡片列表有滚动入场（stagger 交错）；②持续循环——登录卡光扫、登录页光斑漂移、运行中状态点呼吸、对话流式光标、知识库抽取中的不确定进度条、骨架屏 shimmer；③00 画框底部"动效展演"区集中演示全部循环动效，右上"重播入场"可反复观看；④右上切换亮暗有交叉淡化。实现规范见 `frontend/src/design-system/styles/motion.css`（24 篇 §4.9）。

## 与实现的关系

本稿是 M1 前端实现（16 篇规格）的视觉基准：评审通过后，基元组件按 00 画框逐个 story 化，页面按画框组装；验收走 23 篇 DoD + 截图比对（preview/ 即初始基线）。

**样式库已落地为代码**：`frontend/src/design-system/`（tokens.css 五层样式 + preview.html 冒烟页），类名与本画板同名同源——画板看效果、样式库看实现，组件扩充与借鉴来源见 [24 篇](../架构设计/24-前端组件库扩充与外部样式借鉴.md)。
