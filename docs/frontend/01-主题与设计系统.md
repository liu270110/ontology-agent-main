# 01 - 主题与设计系统（Onto Blue · 深空蓝）

> 状态：v0.1 | 日期：2026-09-26 | 上游依据：[架构锚点](../architecture/01-总体架构与分层.md)

---

## 1. 设计原则

本平台是**数据密集 + 图谱密集**的工作台型产品：用户长时间停留，高频执行「读表格、看图谱、填表单、做审核」四类动作。主题设计遵循五条原则：

| # | 原则 | 落地含义 |
| ---- | ---- | ---- |
| 1 | **Token 先行** | 先定主题（本文），再搭脚手架（布局壳），最后写组件；所有组件**只消费 `--onto-*` token，禁止写裸色值** |
| 2 | **工作台密度** | 表格/表单默认紧凑密度（Element Plus `small` 尺寸），行高 40px 内；阅读型页面（对话、审核原文）才用默认密度 |
| 3 | **双主题平等** | 亮/暗主题由同一组 token 的两份取值驱动，不允许「暗色是亮色加个滤镜」；每个 token 必须同时给出两态 |
| 4 | **语义色克制** | 成功/警告/危险/信息只用于状态表达（校验结果、审核结论、任务状态），不做装饰色；大面积区域一律中性色 + 品牌蓝 |
| 5 | **图谱色即语义** | 图谱节点颜色 = 实体类型，全站唯一映射（§4），任何页面不得复用八色板表达其他含义 |

## 2. Design Token 总表

### 2.1 命名规范

- 格式：`--onto-{类别}-{名称}-{修饰}`，如 `--onto-color-primary-500`、`--onto-space-4`、`--onto-radius-card`。
- 类别固定为：`color`（色彩）、`font`（字体）、`space`（间距）、`radius`（圆角）、`shadow`（阴影）、`motion`（动效）、`graph`（图谱）。
- 亮色值声明在 `:root`；暗色值声明在 `html.theme-dark` 下同名覆盖（见 §3）。

## 3. 亮暗双主题机制与 Element Plus 覆盖

### 3.1 机制

- 切换开关 = 在 `<html>` 上加/移 `theme-dark` class（持久化到 `localStorage.onto-theme`，默认跟随 `prefers-color-scheme`）。
- Element Plus 引入其官方暗色变量表（`element-plus/theme-chalk/dark/css-vars.css`，同样挂在 `html.dark`），工程内统一用 `theme-dark` 并同步切换 `dark` class，两者始终一致。
- 组件代码只允许写 `var(--onto-*)`；`--el-*` 的映射只存在于 `styles/element-overrides.scss` 一处。

### 3.2 Element Plus 变量映射（核心片段）

```scss
// styles/element-overrides.scss —— 全仓库唯一允许写 --el-* 映射的文件
:root {
  --el-color-primary: var(--onto-color-primary-500);
  --el-color-primary-light-3: var(--onto-color-primary-400);
  --el-color-primary-light-5: var(--onto-color-primary-300);
  --el-color-primary-light-7: var(--onto-color-primary-200);
  --el-color-primary-light-8: var(--onto-color-primary-100);
  --el-color-primary-light-9: var(--onto-color-primary-50);
  --el-color-primary-dark-2: var(--onto-color-primary-600);
  --el-color-success: var(--onto-color-success);
  --el-color-warning: var(--onto-color-warning);
  --el-color-danger:  var(--onto-color-danger);
  --el-color-error:   var(--onto-color-danger);
  --el-color-info:    var(--onto-color-info);
  --el-text-color-primary:   var(--onto-color-text-title);
  --el-text-color-regular:   var(--onto-color-text-body);
  --el-text-color-secondary: var(--onto-color-text-secondary);
  --el-text-color-placeholder: var(--onto-color-text-secondary);
  --el-border-color: var(--onto-color-border);
  --el-fill-color-light: var(--onto-color-fill);
  --el-bg-color: var(--onto-color-bg-card);
  --el-bg-color-page: var(--onto-color-bg-page);
  --el-border-radius-base: var(--onto-radius-input);
  --el-border-radius-small: 4px;
  --el-font-size-base: 14px;          // 对齐 --onto-font-body
  --el-box-shadow-light: var(--onto-shadow-1);
}
html.theme-dark {                      // 与 EP dark/css-vars.css 同域覆盖，暗色取值生效
  /* --onto-* 暗色值在 tokens.scss 中已在此作用域覆盖，--el-* 自动跟随上面的 var() 引用 */
}
```

> 映射表只需维护一次：`--el-*` 指向 `--onto-*`，暗色覆盖 `--onto-*` 即同时驱动自研组件与 Element Plus 组件。

## 4. 图谱可视化配色规范（八色板）

### 4.1 类型映射（全站唯一）

| 实体类型 | Token | 亮色 | 暗色（描边/高亮用提亮档） | 出现页面 |
| ---- | ---- | ---- | ---- | ---- |
| 类 Class | `--onto-graph-class` | `#2B5CE6` | `#8FAEF8` | 本体工作台、图谱浏览器 |
| 实例 Instance | `--onto-graph-instance` | `#36B37E` | `#6EE7B7` | 图谱浏览器、检索 Playground |
| 属性 Property | `--onto-graph-property` | `#FFAB00` | `#FCD34D` | 本体工作台 |
| 规则 Rule | `--onto-graph-rule` | `#FF5630` | `#FCA5A5` | 本体工作台 |
| 行动 Action | `--onto-graph-action` | `#6554C0` | `#A78BFA` | 图谱浏览器（行动类实体） |
| 约束 Constraint | `--onto-graph-constraint` | `#00B8D9` | `#67E8F9` | 本体工作台（SHACL 节点） |
| 文档 Document | `--onto-graph-document` | `#8993A4` | `#B6BFD1` | 证据链、来源文档节点 |
| 社区 Community | `--onto-graph-community` | `#F5616C` | `#FDA4AF` | GraphRAG global 模式社区摘要 |

### 4.2 使用规则

- **节点**：填充 = 类型色 15% 透明度，描边 = 类型色 1.5px；节点主标签 12px `--onto-color-text-body`，置于节点下方。
- **边**：统一 `--onto-color-text-secondary`（亮）/ `#475569`（暗），1px；边标签仅 hover 或选中路径时显示，白底（亮）/卡片底（暗）小胶囊。
- **选中态**：描边加粗至 2.5px + 类型色 25% 透明度外发光（halo 半径 6px）；多选时 halo 统一用 primary-300。
- **弱化态**：搜索过滤/邻域聚焦时，非相关节点与边透明度降至 0.25，禁用其交互。
- **图例**：所有含图谱的页面必须在画布左下角渲染八色板图例（点击图例项 = 按类型过滤）。
- **禁令**：八色板不得用于非图谱 UI（Tag、图表系列色等）；ECharts 业务图表系列色另用 primary 色阶 + 语义色，不占用图谱语义。

## 5. 组件风格准则

### 5.1 按钮层级

| 层级 | 样式 | 用途（每视图至多 1 个） |
| ---- | ---- | ---- |
| Primary | primary-500 底白字，hover 400、active 600 | 视图主操作：上传文档、提交审核、发布版本 |
| Default | 卡片底 + border 描边 | 次操作：保存草稿、刷新 |
| Text | 无底无框，primary-500 文字 | 行内操作：表格行「查看」「编辑」 |
| Danger | danger 实底，需二次确认弹窗 | 删除本体、回滚版本、移除成员 |

### 5.2 表单 / 表格

- 表单：label 置顶（紧凑）；必填用 danger 色 `*`；校验错误 = 输入框 danger 描边 + 下方 12px 错误文案；工作台右侧属性表单统一用 `JsonSchemaForm`（见 02 篇组件清单）。
- 表格：默认 `size="small"`，行高 40px；斑马纹用 `--onto-color-fill` 50% 透明度；状态列一律用 `StatusBadge`，不用裸 Tag 文本；操作列固定右侧，超过 3 个折叠为「更多」下拉。
- 空/加载：统一空态插画 + 主行动按钮引导（如「上传第一份文档」）；加载用骨架屏（表格）与流式光标（对话）。

### 5.3 卡片 / Tag 语义

- 卡片：`--onto-radius-card` + `--onto-shadow-2`，hover 抬升为 `--onto-shadow-3`（仅可点击卡片）；卡片标题 16px/600 + 右上角操作区。
- Tag 语义色使用（`soft` 底 + 深色字）：
  - 状态类：success=已通过/已发布，warning=待审核/抽取中，danger=已拒绝/校验违例，info=进行中/草稿；
  - 类型类：一律灰色 Tag（`--onto-color-fill` 底），类型区分交给图标与图谱色板，不引入新颜色。

## 6. 图标规范

- 统一使用 `@element-plus/icons-vue` 线性图标（outline 风格，视觉描边 ≈1.5px），不混用面性图标。
- 尺寸三档：16（表格行内/Tag）、20（菜单/按钮）、24（空态/导航组）；颜色跟随文字色或 `currentColor`。
- 自定义图标仅限图谱八类型与平台 Logo，放 `src/assets/icons/`，SVG 单色、`stroke="currentColor"`，经 `vite-svg-loader` 注册。
- 功能语义固定：知识库=Collection、本体=Share（网状）、记忆=Clock、扩展=Puzzle、系统=Setting；全站不得一图标多义。
